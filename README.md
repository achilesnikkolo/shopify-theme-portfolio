# Shopify Theme Portfolio

A Shopify theme I'm building to practice and showcase theme development.
It's based on Shopify's Skeleton theme, and I'm adding my own custom
sections and features on top of it.

## About me
I'm a Senior Technical Support Specialist with hands-on Shopify experience:
theme customization, Liquid, app blocks and embeds, and third-party
integrations like reviews and loyalty widgets. This repo is where I'm
building my development skills on top of that merchant-facing experience.

## Built with
- Liquid
- HTML, CSS, and JavaScript
- Shopify CLI
- Git and GitHub (feature branches and pull requests)

## What I've built
- Customized homepage intro: new heading, description, and background color
- FAQ section: merchant-editable heading, description, and questions using
  blocks, with an accessible open/close layout (no JavaScript)
- More custom sections in progress
- FAQ section: merchant-editable heading, description, and question blocks,
  with options to open the first question by default and to allow only one
  question open at a time (JavaScript custom element)

## Local development
1. Install Shopify CLI
2. Clone this repo
3. Run `shopify theme dev --store your-store-name`
4. Open the preview link shown in the terminal
